Loja & Contato

Aparece no site público. O WhatsApp é usado pelo botão “Tenho interesse”.
Só números importam — o país (55) é adicionado se você esquecer. Deixe vazio para esconder o botão de interesse.
Use {nome} para o nome do produto, {preco} para o preço e {link} para o link do produto.

Fonte de dados do catálogo

Onde os produtos ficam guardados. Escolha entre um arquivo local ou um servidor remoto.
📁 Arquivo local
Salva neste computador (products.json). Publique no GitHub Pages depois.
🌐 Servidor remoto
Conecta a um catálogo hospedado. Edite de qualquer lugar, sem git.
Deixe vazio para usar o arquivo padrão do projeto.

Servidor do painel

Como este painel admin roda. Alterações aqui exigem reiniciar o app.
Informe o endereço público do servidor onde o admin está hospedado. Opcional em uso local.
Se preenchido, outros admins precisam desse token para se conectar a este servidor. Deixe vazio para acesso aberto (uso local).
⚠ Host/porta alterados. Reinicie o app (feche e rode de novo) para aplicar.
